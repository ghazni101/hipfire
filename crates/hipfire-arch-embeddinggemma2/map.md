## Purpose

EmbeddingGemma 2 (`google/embeddinggemma-2`): a 24-layer **bidirectional** Gemma-4-family single-vector embedding encoder — sliding/full hybrid attention with per-layer geometry overrides, half-split RoPE, projection-only PLE, mean-pool + L2 `embedding_projection` head with Matryoshka truncation. **Not a chat model**: no LM head, served only through the non-chat `embed` verb (`hipfire embed`, `POST /v1/embeddings`), sequential or multi-slot. Text-only by design — the checkpoint's vision/audio towers are not loaded and image input is refused. The default tokenizer's greedy SentencePiece path diverges from HF on this vocabulary, so arch 18 opts into the exact SP-BPE merge path (`Tokenizer::enable_sp_bpe_merges`). See the `//!` docs in [`src/lib.rs`](src/lib.rs).
